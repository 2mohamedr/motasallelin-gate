# المتسللين — بوابة الجمهور (QR)

سيرفر بسيط (Express + Socket.io) بمبدأ واحد بس: **بوابة مفتوحة/مقفولة**.
الجمهور يدخلوا بالـQR ويستنوا، وانت بتفتحها لهم كلهم مرة واحدة من لوحة المخرج.

## الروابط اللي هتطلعلك بعد الرفع

- `https://your-app.up.railway.app/` → ده اللينك اللي تحوّله QR code وتلزقه على الكراسي
- `https://your-app.up.railway.app/admin` → ده لوحة المخرج، خاص بيك انت بس (محدش يوصله غيرك)

## إزاي تستخدمها ليلة العرض

1. افتح `/admin` على موبايلك، وادخل بالباسورد اللي حطيتها في `ADMIN_PASSWORD`.
2. الجمهور بيفتحوا الـQR من على الكراسي، هيلاقوا شاشة "استنى شوية..." فيها شرح مختصر
   إزاي هيلعبوا (يختاروا يبقوا إله إيه، يشوفوا قصته، ويشوفوا مصيره).
3. في اللحظة اللي انت حددتها في العرض، تدوس **"افتح اللعبة دلوقتي"** من `/admin`.
4. **كل موبايلات الجمهور بتتحول تلقائي** (من غير ما حد يعمل أي حاجة) لشاشة
   اختيار الإله، لايف في نفس اللحظة.
5. كل واحد يختار دوره بنفسه، ويشوف الجمل التعبيرية عن مصيره، ويقدر يجرب
   إله تاني كذا مرة.
6. لو عايز تقفلها تاني (مثلاً خلص الاستراحة) دوس "قفل اللعبة" من نفس اللوحة.

## خطوات الرفع على Railway

نفس خطوات مشروع البروفة بالظبط:

1. ارفع الفولدر على GitHub:
   ```bash
   cd motasallelin-gate
   git init && git add . && git commit -m "أول نسخة"
   git branch -M main
   git remote add origin <لينك الريبو بتاعك>
   git push -u origin main
   ```
2. على [railway.app](https://railway.app): **New Project → Deploy from GitHub repo**.
3. في **Variables** ضيف `ADMIN_PASSWORD` بالباسورد اللي هتدخل بيها لوحة المخرج.
4. في **Settings → Networking** دوس **Generate Domain** — هيديك اللينك العام.
5. حوّل اللينك الرئيسي (من غير `/admin`) لـ QR code (أي موقع مجاني زي qr-code-generator.com)
   واطبعه ولزقه على الكراسي.

## تشغيل محلي (تجربة قبل الرفع)

```bash
npm install
ADMIN_PASSWORD=test123 npm start
```
افتح `http://localhost:3000` للجمهور، و`http://localhost:3000/admin` للوحة المخرج.

## ملاحظات

- مفيش حسابات أو باسوردات للجمهور خالص — أي حد يفتح اللينك بيشوف نفس التجربة.
- الحالة (مفتوح/مقفول) مش متخزنة في ملف — لو السيرفر اتعمله ريستارت، هترجع "مقفولة"
  تلقائي ولازم تفتحها تاني من `/admin`.
- لو عايز تزود عدد "الآلهة" أو تغيّر النصوص، كل حاجة موجودة في `public/app.js` في
  المتغير `roles` في أول الملف.
